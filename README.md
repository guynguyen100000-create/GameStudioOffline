# GameStudioOffline

Android Studio project in Java. Initial milestone: an offline 2D game creation prototype with a Vietnamese interface. This is a foundation, not yet a full game engine.

## Build
Open the project in Android Studio, wait for Gradle sync, then choose Build > Build Bundle(s) / APK(s) > Build APK(s).

## Planned milestones
- Offline 2D scene editor
- Local save/load
- Play-test mode
- Later: 3D editor and LAN/hotspot multiplayer
